# Asyndetic Coordination

Tovian currently favors **asyndetic coordination**: clauses are placed side by side without an overt coordinator like English “and” or “but.”

## Core pattern

Use two finite clauses in sequence:

- {% tovc "nom.ani-child aux_3_sim_prs sight def.acc.inan-moon, nom.ani-mother aux_3_cnt_prs speech" %}
  — “The child sees the moon, the mother is speaking.”

This is the default strategy for additive coordination. Use `;` or `,` to mark the split between clauses in writing.

## Contrast without a dedicated “but”

Tovian does not have a dedicated contrastive coordinator in the core lexicon. Contrast is expressed through:

- context
- discourse order
- intonation/prosody in speech

Example (contextual contrast by clause order/prosody):

- {% tovc "nom.ani-child aux_3_cnt_prs sleep def.loc.inan-home; nom.ani-dog aux_3_cnt_prs running loc.inan-forest" %}
  — “The child is sleeping at home; the dog is running in the forest.”

## Practical style notes

- Keep each clause complete and explicit.
- Prefer clear case marking on nouns to avoid ambiguity.
- For stronger contrast, place the unexpected clause second.

## Future extension path

If desired, Tovian can later add overt coordinators (e.g., additive, disjunctive, adversative). Until then, clause chaining is grammatical and idiomatic.
