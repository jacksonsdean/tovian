# Time and Calendar

## Time expressions

Use the temporal case prefix {% tovc "temp" %} with time words for “at/on/when”.

### Example
{% tovc "temp.abs.two" %}: “at two o’clock”

For an explicit event-based “when,” use `tu-le-ngothr: P; Q`, “at the time described by P, Q.” The colon opens the event description and the semicolon marks the transition to the main clause. See [temporal clauses](syntax.html) for scope, agreement, and examples.


### Then and afterward

{% tovc "following_stage" %} is a noun meaning **the following time or stage**: the next relevant stage after an event or reference point. It is a lexicalized compound of `time+front`, formed at year 0. The sound-change script develops `nkoθirheθ` into `methr`.

With temporal case and abstract class, {% tovc "temp-abs-following_stage" %} means **“at the following stage,” “then,” or “afterward.”** It refers back to the preceding event or another salient stage. Aspect and context supply the length of the delay and any requirement that the earlier event be completed.

- {% tovc "I aux_1_sim_pst speech, temp-abs-following_stage you aux_2_sim_pst writing" %}.
  — “I spoke, then you wrote.”

The expression uses the ordinary temporal noun phrase. See [temporal clauses](syntax.html) for its use inside a “when” frame.
