# Time and Calendar

## Time expressions

Use the temporal case prefix {% tovc "temp" %} with time words for “at/on/when”.

### Example
{% tovc "temp.abs.two" %}: “at two o’clock”

For an explicit event-based “when,” use `tu-le-ngothr: P; Q`, “at the time described by P, Q.” The colon opens the event description and the semicolon marks the transition to the main clause. See [temporal clauses](syntax.html) for scope, agreement, and examples.
