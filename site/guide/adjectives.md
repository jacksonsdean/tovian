# Attributive Nouns (adjectives)

Descriptive qualities are expressed as nouns placed directly after the noun they modify. Order matters.

- {% tovp "acc-inan-city <b><u> big </u></b> ani-person aux_3_sim_prs   sight" %} 
    - {% tovscript "acc-inan-city big ani-person aux_3_sim_prs sight" %} 
  - `{% tovipa "acc-inan-city big ani-person aux_3_sim_prs sight" %}` 
  - English: The person sees the **big** city.
- {% tovp "acc-inan-city ani-person <b><u> big </u></b> aux_3_sim_prs sight" %}
  - {% tovscript "acc-inan-city ani-person big aux_3_sim_prs sight" %}
  - `{% tovipa "acc-inan-city ani-person big aux_3_sim_prs sight" %}`  
  - English: The **big** person sees the city. (meaning changes)
